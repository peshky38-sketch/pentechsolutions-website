# Pentech Solutions Limited Website

A responsive static business website for Pentech Solutions Limited.

## Included

- `index.html` — all website sections and content
- `styles.css` — responsive styling
- `script.js` — mobile navigation, product filters, WhatsApp enquiry links and email form
- `assets/pentech-logo.png` — logo supplied for this website

## Run locally

1. Extract the ZIP file.
2. Open the `pentech-solutions-website` folder.
3. Double-click `index.html`, or use VS Code Live Server.

## Important notes before publishing

- The contact form uses a `mailto:` link. It opens the visitor's default email application; it does not send email in the background. For a website form that submits without opening an email app, connect a backend or a form service such as Formspree, Web3Forms or a server-side email provider.
- Product photos are illustrative remote images from Unsplash. Replace them with Pentech's actual product and shop photos for the best results. An internet connection is required to load these photos and Google Fonts.
- Product categories are examples. Confirm actual stock, models and prices with the business before publishing.
- Check the exact shop pin and map location before launch. The embedded map searches for Bazaar Plaza, Nairobi.
- The listed business hours are Monday–Saturday, 9:00 AM–6:00 PM, as supplied.

## Deploy

Upload the extracted files to a static hosting provider such as Netlify, Vercel or GitHub Pages. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder together.
