# Pentech Solutions Limited — Lovable-inspired website

Responsive static website built with HTML, CSS and JavaScript, following the page structure and content of the supplied Lovable reference.

## Files

- `index.html` — page content and sections
- `styles.css` — desktop and mobile styling
- `script.js` — mobile navigation and pre-filled WhatsApp enquiry links
- `assets/pentech-logo.png` — logo provided in the chat

## Run locally

Extract the ZIP, open this folder in VS Code, install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**.
